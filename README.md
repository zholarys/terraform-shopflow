# Terraform ShopFlow infrastructure lab

Creates one AWS EC2 instance and a security group in an existing VPC/subnet. SSH is restricted to one administrator IPv4 /32; HTTP and HTTPS allow public traffic. IMDSv2 is required and the root volume is encrypted. This provisions infrastructure only; application deployment lives in `ansible-shopflow`.

## Requirements

Terraform >= 1.5, AWS credentials through the standard credential chain, an existing EC2 SSH key pair and a public subnet with an Internet Gateway route. The subnet must belong to the specified VPC. Select and verify an Ubuntu 22.04/24.04 x86_64 AMI for the selected region; no unverified AMI/OS version is hardcoded.

## Usage

```bash
cp terraform.tfvars.example terraform.tfvars
# Replace every placeholder, including the example administrator IP.
terraform init
terraform fmt -check
terraform validate
terraform plan -out=deployment.tfplan
terraform apply deployment.tfplan
terraform output -raw public_ip
```

AWS resources incur charges. The default instance size is a lab starting point, not a measured capacity recommendation; monitor memory and adjust for the services you deploy. An open port 443 does not install TLS by itself.

Local state is ignored by Git but must be protected and backed up. For team use, configure an authenticated remote backend with encryption and locking before applying, and commit the provider lock file generated by `terraform init`. Do not commit AWS credentials, private keys or plans.

## Cleanup

```bash
terraform plan -destroy
terraform destroy
```

Destroy removes the instance and its root volume. Preserve required application data first.
